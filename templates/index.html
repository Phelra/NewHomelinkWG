Mode de performance

        

          Normal : refresh 5s, diagnostics complets, mesure de latence à chaque cycle.

          Light : refresh 15s, latence désactivée, probes mises en cache 30s — recommandé sur lien VPN faible.

          Ultra : refresh 30s, diagnostics réseau désactivés, charts désactivés — pour Raspberry Pi Zero / Pi 1.

          L'adaptation auto bascule en Ultra temporairement si le CPU dépasse 70 % de manière soutenue.
